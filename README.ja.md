# Pinboard

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

**思考や資料を自由に配置できる、macOS の空間型ノートボード。**

![Pinboard プレビュー](Image/image1.png)

Pinboard は、画面を思考・資料・一時的な情報のための柔軟な空間に変えます。メモを分かりやすい場所へ置き、関連するアイデアを近くにまとめ、大切な内容を作業中も見える状態に保てます。

使い始める前にフォルダを整理する必要はありません。Board を開いてメモを置き、アイデアの広がりに合わせて空間を育てていくだけです。

## 主な機能

- **どこにでも作成：** Board の空いている場所をダブルクリックすると、その位置にメモを作成できます。ウインドウ端では、収まる方向へ自動的に配置されます。
- **無限キャンバス：** 自由に移動し、25% から 250% まで拡大・縮小できます。上部コントロールバーの 100% ボタン、または `⌘0` で、現在の中心位置を保ったまま等倍表示に戻せます。
- **メモ、ファイル、リンク：** テキスト、Markdown、画像、PDF、Web ページを同じキャンバスにまとめられます。
- **充実したリンクプレビュー：** YouTube、TikTok、Bilibili、X、Vimeo、そのほか多くの公開ページの URL を貼り付けるかドロップすると、タイトル、説明、プレビュー画像を取得します。メタデータがないページは、URL と追加日時を備えたシンプルなリンクカードになります。
- **いつものアプリで開く：** PDF をダブルクリックすると標準の PDF アプリ、リンクをダブルクリックすると標準ブラウザで開きます。
- **複数の Board：** 仕事、学習、プロジェクト、一時資料を別々の空間に分けられます。上部のコントロールから Board を作成・切り替えでき、名前はダブルクリックで変更できます。
- **高速検索：** Search をクリックするか `⌘F` を押すと、現在の Board を検索できます。入力中に候補が表示され、一致しないカードは薄くなり、最近の検索履歴を 10 件まで確認できます。
- **柔軟なカード：** 移動、サイズ変更、色変更、折りたたみ、複製、ロック、削除が可能です。クリックしたカードは常に最前面へ移動します。
- **コンパクトな操作部：** カードの操作は内容を邪魔しないようタイトルバーにまとめています。画像の操作ボタンは、その画像にポインタを重ねたときだけ表示されます。
- **画像 OCR：** ローカル画像内の文字を認識し、画像と編集可能なテキストを左右に並べて確認できます。
- **読みやすい Markdown：** ソースとプレビューを切り替えられ、見出し、リスト、コード、リンク、スクロール可能な表に対応しています。
- **Board / Desktop モード：** `⌥ Space` で切り替えます。Desktop モードでは、背後のアプリを操作できる状態のままメモをデスクトップ上に表示できます。
- **グリッドスナップ：** 整然と並べたいときはグリッドを有効にし、自由に配置したいときは無効にできます。
- **自動保存：** 次に Pinboard を開いたときも、Board、メモ、キャンバスの表示位置が保たれます。
- **元ファイルを重複保存しない：** 画像と PDF は通常、Finder 上の元の場所に残ります。Pinboard はアクセス権と軽量なプレビューだけを保持し、macOS がアクセスを維持できない場合に限り非公開の予備コピーを作成します。大きなファイルをメモのデータベースへ保存することはありません。
- **AI チャットの保存：** MCP 対応エージェントに現在の会話の保存を頼むだけで、Markdown の要約を作成し、ChatGPT、Claude、Gemini を判別し、実在する共有リンクがあれば一緒に保存します。

## クイックガイド

| 操作 | 方法 |
| --- | --- |
| テキストメモを作成 | Board をダブルクリックするか、Text ボタンを使う |
| Markdown メモを作成 | Markdown ボタンを使う |
| 画像を追加 | Image ボタンを押して画像を選ぶ |
| PDF を追加 | PDF ボタンを使うか、PDF を Board へドロップまたは貼り付ける |
| Web ページや動画リンクを追加 | Link ボタンを使うか、URL を Board へドロップまたは貼り付ける |
| PDF やリンクを開く | カード内容をダブルクリックするか、Open ボタンを使う |
| キャンバスを移動 | 空いている場所をドラッグするか、マウスまたはトラックパッドでスクロールする |
| キャンバスを拡大・縮小 | ピンチ操作、右下のズーム操作、または上部の 100% ボタンを使う |
| テキストメモを移動 | タイトルバーの任意の場所をドラッグする |
| 画像を移動 | 画像にポインタを重ね、左上のハンドルをドラッグする |
| カードのサイズを変更 | 右下のハンドルをドラッグする |
| タイトルを編集 | タイトル文字をダブルクリックする |
| 色や文字サイズを変更 | パレットまたは文字サイズボタンを使う |
| 折りたたむ／展開する | シェブロンボタンを使う |
| カードを複製 | カードを右クリックする |
| ロック／削除 | タイトルバーの各ボタンを使う |
| 画像内の文字を認識 | 画像にポインタを重ね、OCR ボタンを使う |
| Board の作成・切り替え・名前変更 | Board コントロールを使う。名前変更は名前をダブルクリックする |
| メモを検索 | Search または `⌘F` を使い、Return で最初の結果を開く |
| 現在の AI 会話を保存 | 接続済みの AI クライアントで「このチャットを Pinboard に保存して」と依頼する |
| Board / Desktop モードを切り替え | `⌥ Space` を押す |
| ウインドウを最大化／元に戻す | ウインドウ上端をダブルクリックする |

## MCP 連携

MCP を使うと、AI エージェントが Pinboard にメモを作成し、重要な会話を保存できます。チャット整理の手順は MCP サーバーの指示に組み込まれているため、エージェントは現在の会話からタイトルと Markdown 要約を作成し、サービスを判別してカードを作ります。利用者が内容を事前にまとめる必要はありません。

### 1. Pinboard MCP ヘルパーを確認する

Pinboard を「アプリケーション」フォルダへインストールした場合、ヘルパーは次の場所にあります。

```text
/Applications/Pinboard.app/Contents/MacOS/pinboard-mcp
```

別の場所へインストールした場合は、その `Pinboard.app` 内にある同じパスを使ってください。エージェントの設定には絶対パスを指定します。

### 2. Codex に接続する

```bash
codex mcp add pinboard -- /Applications/Pinboard.app/Contents/MacOS/pinboard-mcp
codex mcp list
```

サーバーを追加したら Codex を再起動してください。デスクトップアプリでは **Settings → MCP servers** を開き、**STDIO** サーバーを追加して、ヘルパーのパスを command に指定することもできます。

### 3. Claude Code に接続する

```bash
claude mcp add --transport stdio pinboard -- /Applications/Pinboard.app/Contents/MacOS/pinboard-mcp
claude mcp list
```

Claude Code で `/mcp` と入力すると、接続状態を確認できます。

### 4. ほかの MCP 対応エージェントに接続する

多くのローカルエージェントでは、次のような設定を使用できます。

```json
{
  "mcpServers": {
    "pinboard": {
      "type": "stdio",
      "command": "/Applications/Pinboard.app/Contents/MacOS/pinboard-mcp",
      "args": []
    }
  }
}
```

設定画面や設定ファイルの場所はエージェントによって異なります。

### 5. AI でメモを作成する

たとえば、エージェントに次のように依頼します。

```text
Pinboard に「今日の予定」というタイトルで、3 件のタスクを含む Markdown メモを作成して。
```

MCP ツール名は `create_note` です。

| パラメータ | 必須 | 内容 |
| --- | --- | --- |
| `content` | はい | メモ本文。最大 20,000 文字 |
| `title` | いいえ | メモのタイトル。最大 200 文字 |
| `kind` | いいえ | `text`（初期値）または `markdown` |
| `x`, `y` | いいえ | カード中心の位置。指定する場合は両方が必要 |
| `theme` | いいえ | `graphite`、`indigo`、`teal`、`amber`、`rose` |

現在、画像は MCP 経由ではなく Pinboard 内から追加します。

### 6. 現在のチャットを保存する

次のように依頼するだけです。

```text
このチャットを Pinboard に保存して。
```

エージェントは `save_chat` ツールを使い、会話を自動的に整理します。Chat カードには生成された Markdown 要約が表示され、左上には ChatGPT、Claude、Gemini のコンパクトなバッジが各サービスのアクセントカラーで表示されます。

| パラメータ | 必須 | 内容 |
| --- | --- | --- |
| `title` | はい | エージェントが生成する簡潔なタイトル |
| `summary_markdown` | はい | 整理された会話の要約。最大 20,000 文字 |
| `provider` | はい | `chatgpt`、`claude`、`gemini`、`other`。エージェントが判別 |
| `share_url` | いいえ | すでに取得できている実在の HTTP(S) 共有リンク |
| `x`, `y` | いいえ | カード中心の位置。指定する場合は両方が必要 |

エージェントは、手作業の要約やサービス選択を利用者へ求めないよう指示されています。また、共有リンクを推測して作ることもありません。AI クライアントが実在する共有リンクを提供できる場合は、Pinboard がカードのタイトルバーにあるリンクボタンへ保存します。リンクがない場合は、リンクボタンなしでカードを保存します。

### MCP のトラブルシューティング

- エージェントが `create_note` または `save_chat` を見つけられない場合は、MCP 一覧に `pinboard` があることを確認し、エージェントを再起動するか新しいタスクを開始してください。
- Pinboard を開けない場合は、command がインストール済み `Pinboard.app` 内のヘルパーを指していることを確認してください。
- Pinboard が複数ある場合は、使用したいアプリのヘルパーを正確に指定してください。
